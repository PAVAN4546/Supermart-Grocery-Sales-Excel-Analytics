# Supermart Grocery Sales – Retail Analytics

## Project Overview
An Excel-based data analytics project focused on analyzing grocery sales, profitability, product performance, discounts, and geographical performance.

## Tools Used
- Microsoft Excel
- PivotTables
- PivotCharts
- Excel Slicers
- Excel Formulas
- Git and GitHub

## Dataset
- 9,994 sales transactions
- Category and Sub-category
- Sales and Profit
- Discount
- Region, State and City
- Order Date

## Project Objectives

### Objective 1: Overall Sales Performance
1. Total sales and profit
2. Category-wise sales contribution
3. Monthly and yearly sales trends
4. Regional sales performance

### Objective 2: Product Performance
1. Category and sub-category sales
2. High-sales, comparatively low-profit analysis

### Objective 3: Profit and Discount
1. Category-wise and region-wise profit
2. Relationship between discount and profit

### Objective 4: Geographic Performance
1. State-wise and city-wise sales
2. High-sales, low-profit locations
