# Supermart Grocery Sales – Excel Analytics Dashboard

## Project Overview
This project focuses on analysing Supermart grocery sales data using Microsoft Excel. It explores sales performance, profitability, product categories, subcategories, regional performance and yearly sales trends through an interactive dashboard.

## Project Objectives
- Analyse overall sales and profit performance.
- Identify high-performing and low-performing categories.
- Understand regional and city-level sales performance.
- Evaluate profit margins and discount patterns.
- Present business insights through an interactive Excel dashboard.

## Dataset Overview
- Total transactions: 9,994
- Columns include Order ID, Customer Name, Category, Sub Category, City, Order Date, Region, Sales, Discount, Profit and State.
- The workbook also contains a calculated Profit Margin column.

## Tools and Techniques
- Microsoft Excel
- Data cleaning and preparation
- Excel formulas
- PivotTables and PivotCharts
- Interactive slicers and timeline
- KPI cards and dashboard visualisation

## Key Business Insights
- Total Sales: ₹1,49,56,982
- Total Profit: ₹37,47,121.20
- Overall Profit Margin: 25.05%
- Total Transactions: 9,994
- Eggs, Meat & Fish is the highest sales-generating category.
- Snacks generates the highest category-level profit.
- Health Drinks records the highest subcategory sales.
- West is the leading region by sales and profit.
- Kanyakumari records the highest city-level sales.

## Business Recommendations
- Improve inventory planning for high-performing categories.
- Review pricing and procurement costs for lower-margin subcategories.
- Strengthen regional sales strategies.
- Evaluate discounts using profitability and sales performance.
- Investigate unusually low transaction counts before making regional decisions.

## Project Conclusion
This project demonstrates how Microsoft Excel can be used to transform raw grocery sales data into meaningful business insights. The interactive dashboard helps users monitor key performance indicators, identify sales trends and support data-driven business decisions.

## Project Limitations
- The dataset contains transactions from Tamil Nadu only.
- Individual product names are not available.
- The North region has only one recorded transaction.
- Monthly sales totals are aggregated across 2015–2018.
